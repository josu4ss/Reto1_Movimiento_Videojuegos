# Ficha del dispositivo: Teclado

## Tecnología de captura
El teclado utiliza interruptores debajo de las teclas.
Cuando presionamos una, el sistema detecta la
pulsación y envía la información al videojuego.

## Tipo de señal
Digital, porque una tecla tiene dos estados
principales: presionada o liberada.

## Ventaja
Permite controlar al personaje con rapidez
y precisión.

## Limitación
No permite controlar de forma gradual la
intensidad del movimiento como un joystick.

## Juego de ejemplo
Minecraft, donde se utiliza el teclado
para controlar el movimiento del personaje.
